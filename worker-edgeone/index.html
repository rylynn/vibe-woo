Vibe Pet 同步服务已部署

把这个地址填进宠物设置的「好友 → 服务器」即可。

支持的端点：

  • POST /api/register — 注册，获取 pet_id 与邀请码
  • POST /api/state — 上报粗粒度状态
  • POST /api/befriend — 用邀请码添加好友
  • GET /api/friends — 拉好友列表
  • POST /api/event — 投递串门/互动事件
  • GET /api/events — 拉取并清空事件队列

隐私：本服务只存宠物过滤后的粗粒度状态（写代码/闲着/离开）， 不接触任何应用名、窗口标题或输入内容。
