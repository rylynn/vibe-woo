Vibe Pet 同步服务已部署

把这个地址（含 /api）填进宠物设置的「好友 → 服务器」即可。

支持的端点：

  • POST /api/register — 邀请码注册，返回 uid / 会话 token
  • POST /api/login — 登录，返回会话 token（90 天滚动续期）
  • POST /api/logout — 登出，吊销当前会话（Bearer）
  • GET /api/me — 我的账号信息（Bearer）
  • POST /api/profile/pet-name — 改宠物名（Bearer）
  • POST /api/friends/add / friends/remove — 加/删好友（Bearer）
  • GET /api/friends — 好友列表（Bearer）
  • POST /api/heartbeat — 心跳，可捎带当日用量计数（Bearer）
  • POST /api/visit / home — 串门 / 回家（Bearer）
  • POST /api/admin/login — 管理员登录（环境变量 ADMIN_USER / ADMIN_PASS）
  • GET /api/admin/overview|users|user?uid= — 数据看板查询（admin Bearer）

隐私：本服务只存宠物过滤后的粗粒度状态（在忙/闲着/离开）与聚合计数 （提醒/速记/番茄/在线分钟），不接触任何应用名、窗口标题或输入内容。
