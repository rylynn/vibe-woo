# MC 形态 M2（动画 + 表情）手工验证清单

M2 的手工验收步骤。对应计划
`docs/superpowers/plans/2026-09-23-mc-forms-m2.md` Task 7 Step 6，
验收口径来自规格 §3（动画与表情）与 §6（性能硬验收）。量化动画、
眼部覆盖、色调已有单测覆盖；这里验证的是「观感、节奏、真机 CPU」。

**状态：待用户执行。** 逐条记录实测结果，未执行不得视为通过。

## 前置

- [ ] `npx vitest run`、`npx tsc --noEmit` 全绿；`pnpm tauri dev` 启动
- [ ] `Ctrl+Alt+M` 切到 MC 形态（全局快捷键，仅 debug 构建）

## 逐项验证

- [ ] **1. 呼吸**：站立时头部以 3 档起伏（无连续抖动/亚像素闪烁），
      约 2.4s 一个周期
- [ ] **2. 眼部**：眨眼自然；视线跟随鼠标（瞳孔 ±1 格 + 头部 7 档转向，
      转头时眼睛不重影、不脱离脸部）
- [ ] **3. 走动**：四肢对侧摆动（右臂+左腿同相），朝左走时整身镜像、
      不出现贴图错乱
- [ ] **4. 动作**：idle 间隙出现 hop（张臂小跳）/ stretch（举臂伸懒腰，
      手心朝上）/ lookaround（左右扫视）且节奏不打扰
- [ ] **5. 抱起**：拖拽宠物时四肢慢速下垂摆动（held 250ms/相位）
- [ ] **6. 睡眠**：锁屏或深夜 → 躺平（脸朝天、脚朝观察者），呼吸只
      抬不沉，闭眼
- [ ] **7. 色调**：专注态提亮（focused）、睡眠/暗态压暗（dim）切换正确，
      无闪烁
- [ ] **8. 深夜疲惫**：黑眼圈出现在眼下
- [ ] **9. CPU（红线）**：活动监视器 → WebContent 进程，三档实测：
      待机 <1%、睡眠档更低、活跃互动时无异常尖峰
- [ ] **10. 尺寸四档**：48/96/144/192 各档锐利；奇数档（48=1×、144=3×）
       的眼部覆盖边缘无半透明雾感
- [ ] **11. 预览**：形象弹窗里 MC 形态有 hop/stretch/lookaround 预览
       动画，与桌面行为一致
- [ ] **12. M1 遗留回归**：
       - 锁屏再回：形态与动画恢复，不崩溃
       - 重启应用：仍为原参数形象（开发切换不持久化）
       - 穿透回归：按 `docs/plans/2026-08-29-m1-verification.md` 过一遍
         （点宠物不抢焦点、透明区穿透、特效不形成隐形墙、
         `Ctrl+Alt+Cmd+Q` 逃生有效）
