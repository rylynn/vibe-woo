# MC 形态 M3（素材 + 设置）手工验证清单

前置：`pnpm tauri dev` 启动。准备素材：一张合法 64×64 PNG 皮肤、
一张超大 PNG（>64KB）、一张非 PNG 图片、一张 64×32 旧格式皮肤（可选）。
窗口/穿透无改动，本清单不覆盖 M1 验证项。

## 1. 旧配置升级兼容
- [ ] 用 1.8.0 的 config.json（参数形象）启动：形象与升级前一致，无报错
- [ ] config.json 手改为 MC 字段（form: "cat"）后启动：猫形态生效且重启保持

## 2. 形象弹窗双页签
- [ ] 设置 → 形象 → 换一批：弹窗顶部出现「参数形象 | MC 形态」页签，默认参数页
- [ ] 当前为 MC 形象时打开弹窗：直接落在 MC 页，当前形态/皮肤已选中
- [ ] 首次领养（清空 config）：弹窗同样双页签，可选 MC 形态领养

## 3. MC 页形态与皮肤
- [ ] 玩家/猫/狗按钮切换：选中高亮，预览动画跟随（跳/伸懒腰/张望）
- [ ] 猫/狗页：显示「猫/狗使用内置形象，皮肤仅对玩家形态生效」，无皮肤格子
- [ ] 玩家页：默认皮肤格 + 「+」导入格 + 已导入皮肤格

## 4. 皮肤导入 / 删除 / 持久化
- [ ] 导入合法 PNG：新格出现并选中；确认后换装；重启后保持
- [ ] 再导入同内容 PNG：不涨数量（去重），名字更新
- [ ] 导入超大 / 非 PNG / 尺寸不对：行内中文提示（不弹系统框、不抢焦点）
- [ ] 删除未使用皮肤：点 × 变「确认」，再点一次才删；点其他处取消
- [ ] 删除正在使用的皮肤：× 禁用（悬停提示使用中）
- [ ] 内置默认皮肤格：无 × 按钮

## 5. 猫/狗动作观感
- [ ] 待机：呼吸起伏 + 尾巴量化摆动（猫约 0.6s/档、狗 0.4s/档），无半透明像素
- [ ] 走路：对角小跑（右前+左后同相），无穿模
- [ ] 小跳：四肢收拢、尾竖起
- [ ] 伸懒腰：play bow（前身低、后身翘）
- [ ] 抱起拖动：四肢下垂慢摆、尾巴下垂
- [ ] 睡眠：侧蜷贴地、闭眼、呼吸只抬不沉
- [ ] still 挂件档：完全静止（含尾摆）
- [ ] 奇数尺寸档（1x / 3x）：眼型覆盖无重影、边缘无半透明

## 6. 性能与残留
- [ ] 猫/狗待机 1 分钟：活动监视器 CPU < 1%
- [ ] dev 构建按 Ctrl+Alt+M：无任何反应（开发入口已移除）
- [ ] 手删皮肤库文件后重启：宠物回退默认皮肤，不空白不崩溃
