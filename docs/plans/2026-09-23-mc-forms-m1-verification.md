# MC 形态 M1（渲染 PoC）手工验证清单

MC 形态 M1 PoC 的手工验收步骤。对应计划
`docs/superpowers/plans/2026-09-22-mc-forms-m1.md` Task 7 Step 7，
验收口径来自规格 `docs/superpowers/specs/2026-09-22-minecraft-forms-design.md`
§6（性能硬验收）与 §8（风险与缓解）。自动化单测覆盖不到的部分
（快捷键、真机帧率、拖拽观感、锁屏、CPU 实测）必须在这里逐条真机验证。

## 前置

- [ ] `pnpm tauri dev` 启动，单测与类型检查全绿
      （`npx vitest run`、`npx tsc --noEmit`）
- [ ] 开发切换入口：`Ctrl+Alt+M`（仅 dev 生效，不持久化）

## 逐项验证（照计划 Task 7 Step 7）

- [ ] **1. Ctrl+Alt+M**：出现 MC 玩家（96px 档），正面为主、顶面与左侧
      2:1 等距露出；边缘为硬像素，无模糊、无半透明雾感
- [ ] **2. 再按 Ctrl+Alt+M**：恢复原参数形象
- [ ] **3. 设置 → 大小切 48/144/192**：各档整数倍锐利，无跳档闪烁
- [ ] **4. 拖拽宠物、poke**：移动/响应正常，脏矩形无残影
      （尤其头顶 2m 剪切区与脚下 1m 下探区）
- [ ] **5. 锁屏再回**：MC 形态恢复渲染不崩溃（睡眠态 M1 暂按站立渲染）
- [ ] **6. 活动监视器 → WebContent 进程**：待机 CPU <1%（红线）
- [ ] **7. 重启应用**：仍是原参数形象（开发切换未持久化）
